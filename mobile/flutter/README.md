# Flutter mobile skeleton

Pinned SDK: Flutter 3.47.8, Dart 3.13.7. `pubspec.lock` pins packages. Android, iOS, and web platform shells are generated by `flutter create` with organization placeholder `com.example`; replace the application ID and signing configuration before distribution.

From this directory run:

```sh
flutter pub get --enforce-lockfile
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build web
```

Native APK/IPA builds need Android SDK or Xcode on a suitable host. B-01 contains no login, storage, sync, or business behavior; those belong to later work orders.
