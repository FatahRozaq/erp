# DATA-RM — Kamus data fisik Phase 2 sampai Enterprise Expansion

**Status:** desain migration sebelum kode. Semua tabel mengikuti [standar database](../engineering/database-standards.md): mutable `id bigint identity PK`, `guid uuidv7 UNIQUE`, tenant/entity scope, `created_at/by`, `updated_at/by`, pasangan `deleted_at/by` bila soft delete diizinkan, `version bigint>0`; append-only memiliki `id/guid/created_*` dan source operation, tanpa update/delete bisnis. `U=uuid`, `N=numeric(20,6)` qty, `M=numeric(20,6)` uang dasar/transaksi, `T=timestamptz`, `D=date`, `S(n)=varchar(n)`, `J=jsonb` tervalidasi schema. Semua FK lokal memakai `_id bigint`, referensi lintas owner `_guid uuid`; index selalu diawali tenant/entity bila scoped. Nilai uang tidak memakai float. `business_operation_guid` dan `(source_guid,action,leg)` unik permanen. Audit/outbox/inbox/idempotency mengikuti runtime owner yang sudah dirancang di [DATA-003](../features/mvp-data-dictionary.md).

## Urutan migration dan seed

1. Phase 2 expand: RFQ/blanket, return tambahan, transfer/bin/wave/count, route/visit/device/push, report projection. Backfill source GUID/version dari MVP; dual-read compare sebelum switch. Seed evaluation/return/warehouse policy synthetic dan reason code.
2. Phase 3 expand: approval graph, budget/expense, promotion, bank/FX, scheduler/connector, intercompany. Seed COA/posting/FX/tax fixture synthetic; publish baru setelah simulasi. Jangan aktifkan hard budget/intercompany sebelum mapping dan owner approval.
3. Expansion expand: BOM/WO, POS, TMS, analytics store/checkpoints. Read-only reporting CDC sebelum forecast. No dual writer saat selective split; ADR khusus dan backfill/reconcile/rollback checkpoint.

Setiap migration mempunyai up dan rencana down/forward-fix sesuai data permanen, constraint `NOT VALID` lalu validate untuk tabel besar, backfill batched dengan checksum, index concurrently bila perlu, dan test restore. Function PostgreSQL untuk cap/stock/credit/journal/budget/forecast checkpoint mengikuti [standar function/migration](../engineering/database-functions-and-migrations.md): signature/grant/volatility berversi dan uji race pada PostgreSQL asli. `deleted_*` hanya pada draft/config yang boleh disoft-delete; posting, movement, bank line, decision, event, dan audit append-only. Retensi, partisi, enkripsi dan residency mengikuti [G-16](../decisions/mvp-business-policy.md#g-16oq-09--data-retensi-dan-lokasi-operasi-indonesia); lifecycle produksi harus disetujui Legal/Security.
